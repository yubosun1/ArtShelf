# ArtShelf 产品设计（v3）

> 方向：**沉浸暗房（Darkroom / Immersive）** · 白昼与暗房主题（含跟随系统）
> 状态：已随 v3 落地；视觉概念稿见 `design-proposals/index.html`

---

## 1. 产品定位

**一个以「此刻」为中心的沉浸式个人品味空间。**

- 不是收藏管理工具，而是观赏 / 聆听 / 阅读的起点与回响
- 封面艺术是唯一视觉主角，UI 全部退后
- 核心叙事：继续品味 > 浏览馆藏 > 记录笔记 > 统计回顾
- 深色是本色（暗房），浅色是「白昼放映厅」（暖纸调而非纯白）；支持跟随系统、白昼放映厅、暗房，可在设置中自由切换

### 设计原则

1. **封面即主角**：封面占据最大视觉权重，文字与控件克制退后
2. **此刻优先**：进行中的作品永远占据首页主导地位，一键继续
3. **环境渲染**：封面主色溢出为环境光晕，界面从藏品中「生长」出来
4. **双色同构**：深浅外观共享布局与令牌，仅调色板与光效强度不同
5. **本地优先**：零云端、无遥测、零配置开箱即用

## 2. 信息架构

顶部 Tab 导航，五个一级入口：

| Tab | 职责 | 快捷键 |
| :-- | :-- | :-- |
| **此刻** | 默认首页：正在品味 Hero + 进行中队列 + 三类精选 + 数据条 | `⌘1` |
| **片库** | 影视全量网格（筛选 / 排序，检索走顶栏全局搜索） | `⌘2` |
| **唱片** | 音乐全量网格（1:1 方形封面墙） | `⌘3` |
| **书架** | 书籍全量网格（2:3 竖版封面） | `⌘4` |
| **统计** | 品味数据回顾 | `⌘5` |

辅助入口：全局搜索（`⌘F`，顶栏常驻）、收录新媒体（`⌘N`，顶栏 ＋）、设置（`⌘ ,`）。

## 3. 关键页面

### 3.1 此刻（Home）

自上而下四个区块：

1. **此刻正在品味（Hero）**：最近一件进行中藏品的大封面（可点击进详情）+ 标题 / 作者 / 年份 / 类型、策展手记摘要、进度条、主按钮「继续观赏」（唤起观看链接或本地文件）、次按钮「记一笔」「全部笔记」、评分。背景为封面主色的虚化环境渲染，底部渐隐融入画布
2. **同时进行（队列）**：其余进行中藏品的小卡片，各带迷你进度条与百分比（≤4 张等宽四列，更多时横滑）
3. **三类精选**：片库精选 / 唱片墙 / 书架各一行横滑封面，卡片附状态徽标与评分，「全部 ›」直达对应 Tab
4. **数据条**：馆藏总量、进行中、本月新增、笔记数、平均评分

### 3.2 片库 / 唱片 / 书架（Library）

- 标题行：库名 + 藏品计数居左，右侧状态筛选（全部 / 进行中 / 已完成 / 待品味）+ 排序（默认添加时间）；检索统一走顶栏全局搜索（§3.6），本页不设搜索框
- 主体：封面网格（影视与书籍 2:3、音乐 1:1），悬停微浮起，状态徽标叠于封面右上角；封面左缘与顶栏、标题行同轴
- **封面右键菜单**：标记已看 / 再看一遍 / 记一笔 / 删除（删除需确认，封面缓存一并清理）——不开详情即可维护
- 空态：引导收录

### 3.3 详情（Detail）

沉浸整版：左侧大封面（带主色光晕），右侧依次为标题 / 元信息 / 标签、评分、策展手记、关联、状态与进度。`Esc` 返回。

- **进度编辑**：拖动进度条 + 步进按钮 +「标记看完」一键置满；**影视可选进度单位**（分钟 / 集 / 期，切换即清空进度重新计量），书籍按页、音乐按音轨
- **观看链接与资料链接分离**：资料链接（豆瓣 / 维基等）由搜索预填、只读、双击打开；在线观看链接由用户手动粘贴，可编辑，旁置「在线观看」按钮（无链接时置灰）
- **再看一遍**：状态重置为进行中、`replayCount +1`、进度清零（规则见 §5）

### 3.4 收录（Add）

关键词搜索 → 多源元数据补全 → 选用预填表单 → 确认收录；支持手动录入与本地 EPUB 拖入提取封面。零 API Key。剧集类结果带回总集数时，收录后自动按「集」建立进度。观看链接不由搜索预填，留给用户手动补。

### 3.5 统计（Stats）

品味数据回顾页，页头与整页琥珀氛围光沿用「此刻」「库页」同一套光语（统计页不归属单一类型色，以品牌强调琥珀贯穿）。内容为 editorial 版式——无卡片壳，数据直接铺在画布上，节标题沿用「此刻」分节行语言（大标题 + EN 副标）：全宽概览行压阵，六个分节以三行双栏交织（窄行类并排、宽图类成行），热力图格子随栏宽自适应放大：

- **概览行**（全宽大数字，与「此刻」数据条同构图）：本月新增、策展笔记、平均评分、完成率、重温、最常品味（原「概览」「品味足迹」两卡合流）
- **馆藏构成**：类型色 donut 环（中心为总数）+ 图例行
- **状态分布**：待品味 / 进行中 / 已完成三态单条堆叠 + 图例行
- **评分分布**：1–5 星琥珀竖条，随星数渐浓
- **月度收录趋势**：近 6 个月收录柱图，按类型三段堆叠（影视蓝 / 音乐琥珀 / 书籍绿）
- **收录热力图**：近 12 周 GitHub 式日历格，按当日收录数四档着色
- **创作者 TOP 榜**：收录件数前 5 的导演 / 艺术家 / 作者

**口径约束**：所有指标必须可从现有字段直接派生；不做「品味时长」类指标（无自动事件追踪，承诺了就是空话）。

### 3.6 全局搜索

Spotlight 式即时搜索：`⌘F` 聚焦顶栏搜索框，输入即出下拉结果（跨三类全字段：标题 / 创作者 / 标签 / 笔记），回车直达详情，`Esc` 关闭。不做独立搜索结果页。

### 3.7 设置（Settings）

- **外观**：三套主题色样（跟随系统 / 白昼放映厅 / 暗房），点选即切
- **应用图标**：象牙画廊与晴空微晶动态切换，默认象牙画廊即系统 icns 同款，随时切回即回退
- **数据**：导出 / 导入 JSON；**存储**：数据目录与封面缓存说明

## 4. 视觉设计系统

### 4.1 调色板（语义令牌）

外观主题给齐全部语义令牌；「跟随系统」= 白昼 / 暗房随系统深浅切换：

| 主题 | 性质 | `bg` | `panel` | `ink` | `ink2` | `ink3` |
| :-- | :-- | :-- | :-- | :-- | :-- | :-- |
| 白昼放映厅 | 浅（暖纸调） | `#F5F4F0` | `#FFFFFF` | `#1B1D23` | `#5A5F6B` | `#9AA0AC` |
| 暗房 | 深 | `#0D0E11` | `#17191F` | `#F2F3F6` | `#A6ABB8` | `#6B7180` |

`rule` / `well` / `track` 按主题深浅取黑 / 白透明度（暗房：白 7% / 7% / 12%；白昼：黑 9% / 5.5% / 12%）。通用令牌：

| 令牌 | 深色（暗房） | 浅色（白昼放映厅） | 用途 |
| :-- | :-- | :-- | :-- |
| `amber`（强调色文字） | `#E8A33D` | `#C07A14` | 进度 / 进行中 / 点睛 |
| `amberBtn`（按钮底） | `#E8A33D` | `#E8A33D` | 主按钮，深浅一致 |
| 状态·已完成 | 底 `#43B581`25% / 字 `#7FE0B2` | 底 `#2B9664`13% / 字 `#2E8F63` | |
| 状态·进行中 | 底 `#E8A33D`26% / 字 `#F5C063` | 底 `#C07A14`14% / 字 `#C07A14` | |
| 状态·待品味 | 底 `#77809A`30% / 字 `#B9C0D4` | 底 `#6E788C`14% / 字 `#6A7386` | |
| 光晕 `ga` / 投影 `gs` | 0.42 / 0.50 | 0.20 / 0.16 | 封面光晕与投影透明度 |
| 环境渲染 `amb` | 1.0 | 0.5 | Hero 背景色渲染不透明度 |

### 4.2 封面与光效

- 封面满幅裁切铺满画框，圆角 8；悬停上浮 6px + 微放大 1.015
- **主色光晕（Glow）**：从封面提取主色，以 `ga` 透明度投下大面积色晕
- **整页氛围场（Ambient）**：「此刻」整页共享 Hero 封面环境光——封面虚化铺底 + 主色径向光团铺满全窗，纵向向画布色连续沉降，并向上溢出至透明顶栏后方；Hero、分节标题、数据条同处一个光场，无横向明暗分层；浅色模式不透明度 0.5
- **库页氛围光（Library Ambient）**：库页页头以类型代表色（影视蓝 / 音乐琥珀 / 书籍绿）投下大半径淡光晕，叠加全页极淡基调 wash 连续沉降；固定于视口顶部并向上溢出至透明顶栏后方，窗口顶部整片共享同一环境光

### 4.3 字体与排版

- 系统字体栈，不设自定义字体
- 标题 800 字重（Hero 44 / 分区 19 / 卡片 12.5）；强调字距 0.02–0.3em
- 进行中强调信息使用琥珀色 + 全大写英文小标

### 4.4 结构尺寸

- 顶栏透明融入主画布（不设独立标题栏色，导航与内容无分界）；分层结构（72pt）：顶部 28pt 红绿灯呼吸与拖拽区，下方 44pt 为 Tab 导航与搜索操作栏，左右边距均与内容区同轴 40pt
- 区块间距 34；封面卡宽 158（2:3 高 237 / 1:1 高 158），库页网格列数随宽度取整、列间距 24–56 动态吃满行宽，此刻页精选行间距 20
- Hero 封面 236×354；队列卡迷你封面 40×56（方形 40×40）
- 全应用滚动条隐藏

## 5. 数据口径

`MediaItem`：标题、创作者、年份、类型、简介、封面、评分（0–5）、标签、状态、关联文件、**观看链接 `webURL`（手动补）/ 资料链接 `referenceURL`（搜索预填、只读查阅）**、添加与最近浏览时间。

> 链接归位是常驻规则：资料站域名（豆瓣 / 维基 / TVMaze / iTunes / Google Books）不会留在 `webURL`——库加载时一律归位到 `referenceURL`（资料站不是观看入口，即使用户误填也按此纠正）。

v3 关键字段：

- **进度 `progressCurrent` / `progressTotal` / `progressUnit`**：影视可选分钟 / 集 / 期，书籍=页、音乐=音轨，折算 0–1 展示
- **最近品味时间 `lastTastedAt`**：驱动「此刻」Hero 与队列排序
- **策展手记条目化**：多条 `NoteEntry`（时间 + 正文），按时间倒序
- **重温次数 `replayCount`**：由「再看一遍」流转累加

### 状态流转规则（自动副作用）

- 待品味 → 进行中：`lastTastedAt` 置为当前时间
- 任意 → 已完成：进度自动补满（`progressCurrent = progressTotal`；无总量时清 0）
- 再看一遍：状态 → 进行中，`replayCount +1`，进度清零，`lastTastedAt` 置为当前
- 媒体唤起成功（Hero「继续观赏/聆听/阅读」按钮、详情页双击关联文件 / 观看链接 / Apple Music 链接、「在线观看」按钮）：待品味 → 进行中（视为开始品味），其余状态仅刷新 `lastTastedAt`；唤起失败不计
- `lastTastedAt` 刷新时机：上述流转、媒体唤起成功、进度正增量；仅录入总量或进度无变化不刷新
- 已完成条目进度被拉离满值：回落进行中（视为「其实没看完」）
- 编辑总量 / 切换进度单位是元数据修改：不触发流转；编辑总量不截断已记录进度（超出部分展示层钳制），切换单位则清空进度重新计量

## 6. 快捷键

| 快捷键 | 功能 |
| :-- | :-- |
| `⌘1`–`⌘5` | 切换五个 Tab |
| `⌘N` | 收录新媒体 |
| `⌘F` | 聚焦全局搜索 |
| `⌘ ,` | 设置 |
| `Esc` | 分层关闭 搜索浮层 / 详情 / 收录 |

封面悬停微浮起；详情中双击关联文件 / 资料链接唤起系统默认应用。

## 7. 非目标（v3 不做）

- 不做账号体系、云同步、社交分享
- 不做 iOS / iPadOS / Web 版本
- 不做播放器 / 阅读器内建（一律唤起系统默认应用）
- 不做批量多选操作（单项右键菜单 + 快捷键已覆盖）
- 不做合集 / 单集管理（剧集季度、唱片曲目）：一件藏品一条记录
- 不引入任何 API Key 配置

## 8. 版本迁移承诺

v2 用户数据（`library.json` + `covers/`）首次启动 v3 时无损迁移：迁移前备份原文件，失败保留原状并提示，绝不覆盖用户数据。机制与容错见 `tech-architecture.md` §3.3。
