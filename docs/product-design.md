# ArtShelf v3 产品设计方案

> 方向：**沉浸暗房（Darkroom / Immersive）** · 深浅双色随系统切换
> 状态：已定稿（视觉概念稿见 `design-proposals/index.html`）
> 分支：`redesign/v3`

---

## 1. 背景与诊断

v2 的问题不是功能缺失，而是产品定位模糊：**「管理工具」的骨架套了「画廊」的皮**——首页像报表，拟物封面与极简界面互相打架，策展叙事与用户笔记没有被表达，「此刻正在看什么」这一最高频意图在首页没有主导地位。

## 2. 产品定位

**一个以「此刻」为中心的沉浸式个人品味空间。**

- 不是收藏管理工具，而是观赏 / 聆听 / 阅读的起点与回响
- 封面艺术是唯一视觉主角，UI 全部退后
- 核心叙事：继续品味 > 浏览馆藏 > 记录笔记 > 统计回顾
- 深色是本色（暗房），浅色是「白昼放映厅」（暖纸调而非纯白）；两种外观一等公民，跟随系统切换

### 设计原则

1. **封面即主角**：封面占据最大视觉权重，文字与控件克制退后
2. **此刻优先**：进行中的作品永远占据首页主导地位，一键继续
3. **环境渲染**：封面主色溢出为环境光晕，界面从藏品中「生长」出来
4. **双色同构**：深浅外观共享布局与令牌，仅调色板与光效强度不同
5. **本地优先**：零云端、无遥测、零配置开箱即用（沿用 v2 承诺）

## 3. 信息架构

顶部 Tab 导航（取代 v2 左侧栏），五个一级入口：

| Tab | 职责 | 快捷键 |
| :-- | :-- | :-- |
| **此刻** | 默认首页：正在品味 Hero + 进行中队列 + 三类精选 + 数据条 | `⌘1` |
| **片库** | 影视全量网格（搜索 / 筛选 / 排序） | `⌘2` |
| **唱片** | 音乐全量网格（1:1 方形封面墙） | `⌘3` |
| **书架** | 书籍全量网格（2:3 竖版封面） | `⌘4` |
| **统计** | 品味数据回顾 | `⌘5` |

辅助入口：全局搜索（`⌘F`，顶栏常驻）、收录新媒体（`⌘N`，顶栏 ＋）、设置（`⌘ ,`）。

## 4. 关键页面

### 4.1 此刻（Home）

自上而下四个区块：

1. **此刻正在品味（Hero）**：最近一件进行中藏品的大封面 + 标题 / 作者 / 年份 / 类型、策展手记摘要、进度条、主按钮「继续观赏」（唤起关联文件或链接）、次按钮「记一笔」「全部笔记」、评分。背景为封面主色的虚化环境渲染
2. **同时进行（队列）**：其余进行中藏品的小卡片横列，各带迷你进度条与百分比
3. **三类精选**：片库精选 / 唱片墙 / 书架各一行横滑封面，卡片附状态徽标与评分，「全部 ›」直达对应 Tab
4. **数据条**：馆藏总量、进行中、本月新增、笔记数、平均评分

### 4.2 片库 / 唱片 / 书架（Library）

- 顶部：搜索框 + 状态筛选（全部 / 进行中 / 已完成 / 待品味）+ 排序（智能权重 / 最近浏览 / 添加时间 / 标题 / 评分，沿用 v2）
- 主体：封面瀑布网格，影视与书籍 2:3 竖版、音乐 1:1 方形；悬停微浮起，状态徽标叠于封面右上角
- **封面右键菜单**：标记已看 / 再看一遍 / 记一笔 / 删除（删除需确认，封面缓存一并清理）——不开详情即可维护
- 空态：引导收录

### 4.3 详情（Detail）

沉浸整版（不再是小弹窗）：左侧大封面（带主色光晕），右侧依次为标题 / 元信息 / 标签、评分、策展手记列表（多条、按时间倒序）、关联文件与链接（双击唤起）、状态与进度。`Esc` 返回。

- **进度编辑**：拖动进度条 + 步进按钮（影视 ±10 分钟、书籍 ±10 页、音乐 ±1 轨）+「标记看完」一键置满
- **再看一遍**：状态重置为进行中、`replayCount +1`、进度清零（规则见 §6）

### 4.4 收录（Add）

沿用 v2 能力：关键词搜索 → 多源元数据补全（影视 Wikipedia/TVMaze/Apple、音乐 iTunes、书籍 Google Books）→ 确认收录；支持手动录入与本地 EPUB 拖入提取封面。零 API Key。

### 4.5 统计（Stats）

品味数据回顾页：馆藏构成、状态分布、评分分布、本月新增、笔记数。

**口径约束**：所有指标必须可从现有字段直接派生；不做「品味时长」类指标（无自动事件追踪，承诺了就是空话）。

### 4.6 全局搜索

Spotlight 式即时搜索：`⌘F` 聚焦顶栏搜索框，输入即出下拉结果（跨三类全字段：标题 / 创作者 / 标签 / 笔记），回车直达详情，`Esc` 关闭。不做独立搜索结果页。

## 5. 视觉设计系统

### 5.1 调色板（语义令牌，深浅双套）

| 令牌 | 深色（暗房） | 浅色（白昼放映厅） | 用途 |
| :-- | :-- | :-- | :-- |
| `bg` | `#0D0E11` | `#F5F4F0` | 窗口主画布 |
| `titlebar` | `#101116` | `#ECEAE3` | 标题栏 |
| `panel` | `#17191F` | `#FFFFFF` | 卡片 / 浮层 |
| `ink` | `#F2F3F6` | `#1B1D23` | 一级文字 |
| `ink2` | `#A6ABB8` | `#5A5F6B` | 次级文字 |
| `ink3` | `#6B7180` | `#9AA0AC` | 三级文字 |
| `rule` | 白 7% | 黑 9% | 发丝分隔线 |
| `well` | 白 7% | 黑 5.5% | 内凹槽（搜索框 / 按钮底） |
| `track` | 白 12% | 黑 12% | 进度条轨道 |
| `amber`（强调色文字） | `#E8A33D` | `#C07A14` | 进度 / 进行中 / 点睛 |
| `amberBtn`（按钮底） | `#E8A33D` | `#E8A33D` | 主按钮，深浅一致 |
| 状态·已完成 | 底 `#43B581`25% / 字 `#7FE0B2` | 底 `#2B9664`13% / 字 `#2E8F63` | |
| 状态·进行中 | 底 `#E8A33D`28% / 字 `#F5C063` | 底 `#C8820F`15% / 字 `#AE6F0F` | |
| 状态·待品味 | 底 `#77809A`30% / 字 `#B9C0D4` | 底 `#6E788C`14% / 字 `#6A7386` | |
| 光晕 `ga` / 投影 `gs` | 0.42 / 0.50 | 0.20 / 0.16 | 封面光晕与投影透明度 |
| 环境渲染 `amb` | 1.0 | 0.5 | Hero 背景色渲染不透明度 |

### 5.2 封面与光效

- 封面圆角 8；悬停上浮 6px + 微放大 1.015
- **主色光晕（Glow）**：从封面提取主色，以 `ga` 透明度投下大面积色晕
- **Hero 环境渲染（Ambient）**：封面主色 2–3 个径向渐变铺开 + 高斯模糊，浅色模式不透明度 0.5

### 5.3 字体与排版

- 系统字体栈，不设自定义字体
- 标题 800 字重（Hero 44 / 分区 19 / 卡片 12.5）；强调字距 0.02–0.3em
- 进行中强调信息使用琥珀色 + 全大写英文小标

### 5.4 结构尺寸

- 内容左右边距 40，区块间距 34；封面卡宽 158（2:3 高 237 / 1:1 高 158），行间距 20
- Hero 封面 236×354；队列卡迷你封面 40×56（方形 40×40）

## 6. 数据模型

`MediaItem`：标题、创作者、年份、类型、简介、封面、评分（0–5）、标签、关联文件 / 链接、状态、添加与最近浏览时间。

v3 新增 / 调整：

- **进度 `progressCurrent` / `progressTotal`**：影视=分钟、书籍=页、音乐=音轨，折算 0–1 展示
- **最近品味时间 `lastTastedAt`**：驱动「此刻」Hero 与队列排序
- **笔记条目化**：策展手记为多条 `NoteEntry`（时间 + 正文），详情页按时间倒序
- **重温次数 `replayCount`**：由「再看一遍」流转累加

### 状态流转规则（自动副作用）

- 待品味 → 进行中：`lastTastedAt` 置为当前时间
- 任意 → 已完成：进度自动补满（`progressCurrent = progressTotal`）
- 再看一遍：状态 → 进行中，`replayCount +1`，进度清零，`lastTastedAt` 置为当前

## 7. 交互与快捷键

| 快捷键 | 功能 |
| :-- | :-- |
| `⌘1`–`⌘5` | 切换五个 Tab |
| `⌘N` | 收录新媒体 |
| `⌘F` | 聚焦全局搜索 |
| `⌘ ,` | 设置 |
| `Esc` | 关闭详情 / 弹层 |

封面悬停微浮起；详情中双击关联文件 / 链接唤起系统默认应用（沿用 v2）。

## 8. 非目标（v3 首期不做）

- 不做账号体系、云同步、社交分享
- 不做 iOS / iPadOS / Web 版本
- 不做播放器 / 阅读器内建（一律唤起系统默认应用）
- 不做批量多选操作（单项右键菜单 + 快捷键已覆盖）
- 不做合集 / 单集管理（剧集季度、唱片曲目）：一件藏品一条记录
- 不引入任何 API Key 配置

## 9. 版本迁移

- v2 用户数据（`library.json` + `covers/`）首次启动 v3 时无损迁移：字段映射 + 新字段默认值
- 迁移前备份原文件；失败保留原状并提示，不覆盖用户数据
